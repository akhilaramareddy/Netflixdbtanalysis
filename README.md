# Netflix Data Analytics Pipeline with dbt & Snowflake

📌 **Overview**  
This project demonstrates an **end-to-end ELT pipeline** for Netflix/MovieLens data using **AWS S3**, **Snowflake**, and **dbt**. It transforms raw CSV files into **analytics-ready models** while tracking historical changes and ensuring data quality.

🚀 **Use Case**  
- Analyze user ratings, movie tags, and viewing patterns.  
- Track historical changes in tags and metadata using **snapshots**.  
- Generate clean, aggregated tables for analytics and business insights.

🏗 **Architecture**  
- **Raw Layer** – CSV files stored in S3.  
- **Staging Layer** – Cleaned and standardized data using dbt staging models.  
- **Analytics Layer** – Fact and dimension tables, incremental models, ephemeral logic, and snapshots for historical tracking.  
- **Documentation & Lineage** – Auto-generated by dbt for model dependencies and DAG visualization.

🛠 **Tools & Services Used**  
- **AWS S3** – Storage for raw data.  
- **Snowflake** – Cloud data warehouse.  
- **dbt** – Data transformations, models, snapshots, macros, and tests.  
- **Python** – Environment setup and dbt execution.

📂 **Project Workflow**  
1. Ingest raw CSVs into Snowflake tables.  
2. Define dbt sources, seeds, and staging models.  
3. Build intermediate and final models (tables, incremental, ephemeral).  
4. Implement snapshots for Slowly Changing Dimensions.  
5. Apply macros and tests to enforce data quality.  
6. Generate analysis queries and documentation for lineage.

📊 **Datasets**  
- **Movies** – Metadata of Netflix movies.  
- **Ratings** – User ratings of movies.  
- **Tags** – User-assigned tags for movies.

⚙️ **Prerequisites**  
- AWS S3 bucket with raw CSVs.  
- Snowflake account and warehouse.  
- dbt installed with Snowflake adapter.  
- Python environment.

📜 **Execution Steps**  
1. Configure dbt profiles and Snowflake connection.  
2. Load raw data from S3 into Snowflake tables.  
3. Run dbt to build staging, intermediate, and final models.  
4. Execute snapshots and tests to validate data.  
5. Generate documentation and explore lineage using dbt docs.

🏆 **Key Features**  
- **Incremental models** for efficient processing of large datasets.  
- **Snapshots** to track historical changes in data.  
- **Macros** for reusable logic and surrogate keys.  
- **Tests** for data quality (unique, not null, relationships).  
- **Documentation & DAG** to visualize model dependencies.
